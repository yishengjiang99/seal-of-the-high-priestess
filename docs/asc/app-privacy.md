# App Privacy answers (App Store Connect → App Privacy)

Keep in sync with `ios/HighPriestess/Resources/PrivacyInfo.xcprivacy` and
https://grepawk.com/high-priestess/privacy. Last updated 2026-10-07 for in-app purchases (build 2+).

**Do you or your third-party partners collect data from this app?** Yes.
**Tracking (ATT)?** No. No data is used for tracking, and there are no third-party SDKs.

| Data type (ASC category) | Collected | Linked to user | Tracking | Purposes | What exactly |
|---|---|---|---|---|---|
| Identifiers → **User ID** | Yes | Yes | No | App Functionality | Random player ID / install ID generated by the app (Keychain). Not the Apple ID, IDFA or IDFV. |
| User Content → **Gameplay Content** | Yes | Yes | No | App Functionality | Cloud save slots + game settings. |
| Purchases → **Purchase History** | Yes | Yes | No | App Functionality | App Store signed transactions (product, transaction ids, date, environment, ownership) + App Store Server Notification refund/revoke records. Used to verify and restore entitlements. |
| Usage Data → **Product Interaction** | Yes | Yes | No | Analytics | First-party events only: `paywall_shown`, `purchase`, `restore`, `region_complete` (+ placement, product id, app version). Stored on our server, aggregate counts only, 13-month retention. |

Not collected: contact info, health, financial info (payment details stay with Apple), location,
sensitive info, contacts, browsing/search history, diagnostics, other usage data, advertising data.

Notes for the questionnaire:
- "Purchase History" is linked because entitlements are stored per player ID (refund revocation via ASSN v2).
- "Product Interaction" purpose is **Analytics** only (not Developer's Advertising, not Third-Party Advertising).
- Deletion: Settings → Delete cloud data removes all of the above from the server (`DELETE /v1/me`).
